# EM-scaling summary

**Goal.** Extend the paper's headline QK→QK steering result on
Qwen2.5-14B-Instruct (`docs/main.tex`, section `sec:em`) to other open-weight
model sizes and compare against (i) Arditi et al.'s SAE-DoM baseline
([LessWrong](https://www.lesswrong.com/posts/NCWiR8K8jpFqtywFG/finding-misaligned-persona-features-in-open-weight-models))
and (ii) the published EM-finetune's own coherent-misalignment rate.

**Cells.** `{qwen-7b, llama-8b, qwen-32b} × {medical, finance, sports}` =
9 (base, domain) cells. Qwen-14B is the paper's reference cell and lives
upstream (`phase1_fra_orchestrator.py`).

## Setup

| | |
|---|---|
| Recipe A (paper) | **FRA QK→QK** — rank top-K SAE features by QK pair attribution; rescale them at the SAE's hookpoint. |
| Recipe B (baseline) | **DoM steering** — `dom = mean(EM_act) − mean(base_act)` over a probe set; subtract `α·dom` from EM activations. |
| Judge | GPT-4o, paired prompts for alignment (0–100) and coherence (0–100). Same primitives as `phase1_judge_and_combine.py`. |
| Headline metric | best alignment over the α-sweep subject to coherence ≥ 70 (paper convention). |
| Eval prompts | The 8 canonical EM-eval prompts from `fra/em_evaluation.py` (`EM_EVAL_PROMPTS`). Three eval seeds per cell. |
| Hardware | one NVIDIA H200 (143 GB VRAM), bf16 inference. |

### Per-base configuration

| base | n_layers | default layer | hookpoint | SAE |
|---|---:|---:|---|---|
| `qwen-7b` | 28 | 15 | `hook_resid_post` | andyrdt L15 trainer 1 |
| `llama-8b` | 32 | 15 | `hook_resid_post` | andyrdt L15 trainer 1 |
| `qwen-14b` | 48 | 24 | `ln1.hook_normalized` | paper's published SAE |
| `qwen-32b` | 64 | 40 | `ln1.hook_normalized` | **to be trained** |

**Methodological caveat.** Qwen-7B and Llama-8B use SAEs trained at
`hook_resid_post` (andyrdt only published there), whereas the paper does
QK→QK at `ln1.hook_normalized`. The QK→QK intervention at `resid_post`
therefore perturbs the residual stream that feeds *every* downstream
layer rather than only one layer's QK/OV. This is the closest off-the-shelf
SAE for these bases; train-from-scratch ln1 SAEs would close the gap if
the resid_post result is interesting enough to chase.

## Pipeline

1. `experiments/em_scaling/phase0_smoke.py` — load each (base, domain),
   attach the SAE, run a 3-prompt rollout. Sanity check that the registry
   resolves and the hookpoint exists.
2. `experiments/em_scaling/phase1_fra_qkqk.py` — for one (base, domain)
   and one `eval_seed`: head-attribution sweep (if registry has default_head=0),
   rank top-K QK-pair features, sweep α ∈ {0, 0.5, 1, 1.5, 2, 3}, write
   `qualitative_FRA_<base>_<domain>_evalseed<N>.json`.
3. `experiments/em_scaling/phase2_dom_steering.py` — load EM → capture
   probe-set mean activation → unload → load base → capture → compute
   `dom = mean(EM) − mean(base)` → reload EM → sweep α ∈ {0, 0.5, 1, 1.5, 2, 3, 4},
   write `qualitative_DoM_<base>_<domain>_evalseed<N>.json`.
4. `experiments/em_scaling/phase_judge.py judge ...` — GPT-4o judge each
   qualitative JSON in place, then `... combine ...` across the three
   eval seeds per cell.
5. `reproduce/em_scaling/em_scaling_chain.sh` — autoresearch chain that
   runs 1–4 for every cell sequentially and pushes after each cell.
