# Paper bundle (anonymous submission)

This bundle reproduces every figure in the paper from pre-computed JSON inputs. Two experimental codepaths are included:

- `experiments/em/` — emergent-misalignment cross-domain replication on Qwen-2.5-14B (medical, finance, sports)
- `experiments/sleepers/` — TinyStories sleeper-steering replication

Each figure has a one-line reproduction script under `reproduce/`. The data dependencies (judged GPT-4o aggregates for EM; metric-sweep aggregates for sleepers) are pre-computed and live in `data/`.

## Quick start

```bash
# 0. Python deps
pip install matplotlib numpy

# 1. Make every figure
bash reproduce/em/headline_per_domain.sh
bash reproduce/em/cross_domain_panel.sh
for d in medical finance sports; do bash reproduce/em/seed_grid.sh "$d"; done
bash reproduce/sleepers/headline_combined_50k.sh
bash reproduce/sleepers/jsd_2x2.sh
bash reproduce/sleepers/pareto_overlay.sh

# Outputs land in figures/em_figures/ and figures/sleeper_figures/
```

## Anonymisation

This branch is curated to be name-free for ICML anonymous submission:

- No contributor names appear in plot scripts, figure labels, captions, or paper body.
- Internal HF repo IDs and directory names (e.g. `<vendor>/<sae>` or `<contributor>_repl/...`) are confined to data-fetch helpers — not the paper bundle.
- Data file naming uses neutral identifiers (e.g. `published_l24_ln1_sae`, `single_feature_4k`).

When a new contributor name shows up, audit before merge: `grep -rE "<name>" reproduce/ experiments/ scripts/ figures/`.

## Data provenance (what's in `data/`)

`data/em/combined/gpt4o_combined_*.json` — per-(SAE, domain) cross-seed summaries with peak / baseline / min@coh70 / Δ@coh70 metrics. Produced by `experiments/em/phase1_judge_and_combine.py` from the judged qualitative JSONs of 9 (domain × seed) eval streams.

`data/sleepers/sweep_full_metrics.json`, `jsd_2x2_sweep_saeseed.json`, `pareto_seed{0,1,2}.json` — output of the metric-sweep scripts in `experiments/sleepers/`. See `experiments/sleepers/README.md`.

To regenerate any input file from raw model outputs, see `experiments/{em,sleepers}/README.md`.
